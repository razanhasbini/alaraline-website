# Same model, different hair types (free, no watermark)

**Tool:** Qwen Image Edit on Hugging Face. It's free, adds no watermark, and its license (Apache 2.0) allows commercial use.
Open https://huggingface.co/spaces/linoyts/Qwen-Image-Edit-2511-Fast (or search "Qwen Image Edit" on huggingface.co/spaces). Signing in with a free account gives more daily generations.

**Steps (repeat for each hair type):**
1. Upload `model.jpg` from this folder.
2. Paste one prompt below. If there's a "rewrite prompt" option, turn it off.
3. Generate. If the face, tee, pose or background changes, generate again.
4. Download the result and name it exactly: `straight.png`, `curly.png` or `coily.png`.
5. Put the files in this folder and tell Claude. They'll be processed and added to the swipe automatically.

**Shared ending (already included in each prompt):** keep the same woman from behind, the same pose, white t-shirt, pink creamy background, lighting and framing.
